## О практике
Практика состоит из трёх кейсов:
1. Кейс 1. Поиск нетипичного поведения заявок на закупку (папка `case1`).
2. Кейс 2. Восстановить процесс по журналу событий (папка `case2`, в работе).
3. Кейс 3. Генерация продуктовых гипотез (папка `case3`, в работе).

## Цель практики
Научиться анализировать журналы событий и данные: находить нетипичное поведение, восстанавливать бизнес-процесс по логам и формулировать продуктовые гипотезы, а также закрепить навыки работы с Python.
